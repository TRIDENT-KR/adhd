# 기존 프롬프트 테스트 → MORA Eval

공식 평가 도구는 **[MORA Eval — MORA AI 평가 하네스](../../../../tools/mora-eval/README.md)**입니다.

기존 러너는 날짜·대상·수정값을 충분히 채점하지 못하고 운영 프롬프트와 분리되어 있어 종료했습니다. `run_test.mjs`와 `run_test.ts`는 이전 안내를 따라 실행해도 API를 호출하지 않고 새 위치를 안내합니다.

`sample_inputs.json`과 `prompt.mjs`는 과거 실험 이력으로만 보존합니다. 새 평가에 입력하거나 기존 PASS 수치를 모델 정확도로 인용하지 마세요. 새 사용법·지표·동일 데이터 비교·사람 검수 절차는 위 문서를 따릅니다.
